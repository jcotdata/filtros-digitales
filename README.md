# Práctica: Diseño de Filtros Digitales (Pasa Bajos, Pasa Altos y Pasa Bandas)

Repositorio destinado al desarrollo de la simulación y análisis de filtros digitales implementados en Python.

## Descripción del Proyecto
Este proyecto contiene scripts para la generación de señales de prueba ruidosas, diseño de filtros digitales (FIR e IIR tipo Butterworth), aplicación práctica sobre las señales y visualización comparativa de los resultados en el dominio del tiempo y la frecuencia.

## Contenido del Repositorio
- `filtro_digital.py`: Script principal con la simulación completa.
- `requirements.txt`: Dependencias del proyecto (`numpy`, `scipy`, `matplotlib`).
- `assets/`: Carpeta con capturas de pantalla de las gráficas generadas.
